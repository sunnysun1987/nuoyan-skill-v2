# Nuoyan V2.2.1 发布验收记录

## 版本与范围

- 发布候选分支：`codex/v2.2.1-release`
- 验收日期：2026-08-05（Asia/Shanghai）
- 运行环境：Python 3.11.15 隔离虚拟环境
- 验收范围：标准报告内容融合、六页签完整性、CI 严格门禁、wheel 资源完整性、非编辑安装、CLI 核心体检、OpenAlex/PubMed 最小联网闭环

## 缺陷重放与修复

1. 在修复前代码上运行专项回归测试，`report_sections.jsonl` 的已校验分析未进入标准主报告，测试按预期失败。
2. 标准报告生成器已改为融合匹配的 17 章专项内容，同时保留研发阅读入口、指标事实、核心必读文献、全部证据卡和资料缺口页签。
3. CI 改为运行 `nuoyan doctor --strict --json`，并增加版本标签触发、Python 编译和差异检查。
4. Python 3.11 干净环境暴露出翻译安装测试依赖本机 Argos 状态；测试已改为显式模拟依赖状态并禁止模型安装子进程。
5. 非编辑安装后生成标准报告曾因 wheel 缺少模板和样式失败；报告资源现已纳入 `ivd_research` 包，并增加 wheel 内容与双份资源一致性测试。

## 确定性验证

```bash
python -m pytest
ruff check scripts/
python -m compileall -q scripts
git diff --check
```

结果：`211 passed, 1 skipped`；Ruff、编译和差异检查通过。跳过项为显式联网验收，不代表失败。

版本和 CI 契约检查同时确认：

- `pyproject.toml`、`WORKFLOW_VERSION`、README 最新版本均为 `2.2.1`。
- `SKILL.md` 不含废弃加载标识。
- CI 对 `main`、PR 和 `v*` 标签运行，严格 doctor 失败会返回非零状态。
- 构建 wheel 包含六个报告模板/样式资源。

## 隔离安装与 CLI 验证

在 Python 3.11 隔离环境完成非编辑安装后：

- 安装分发版本为 `nuoyan-skill-v2 2.2.1`，导入路径位于隔离环境 `site-packages`。
- `nuoyan --help` 正常显示完整命令集。
- `nuoyan doctor --strict --json` 返回 `ok=true`、`core_ready=true`。
- 通过安装后的 CLI 创建 RSV 冒烟任务并生成标准交付主报告。
- 生成的 HTML 包含 17 个项目分析章节，以及项目分析、研发阅读入口、指标事实、核心必读文献、全部证据卡、资料缺口六个页签。
